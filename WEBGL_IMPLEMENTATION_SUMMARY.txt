🎯 TROUBLESHOOTING RÁPIDO

Problema: "Could not create a WebGL context, Sandboxed = yes"
Solução: Rebuildar com novo next.config.js
  $ docker-compose down -v
  $ docker-compose up --build

Problema: Performance Baixa
Solução: Ativar hardware acceleration
  - Chrome: chrome://settings/system → ativar "Hardware acceleration"
  - Edge: edge://settings/system → ativar "Hardware acceleration"
  - Firefox: about:config → layers.acceleration.force-enabled = true

Problema: Aviso "Performance Baixa: Usando renderer de software"
Solução: É aviso normal se usando software renderer
  - Ativar hardware acceleration (acima)
  - Ou usar navegador em máquina com GPU

Problema: Container não inicia
Solução: Aumentar memória e limpar cache
  $ docker-compose down -v
  $ docker volume prune
  $ docker builder prune -a
  $ docker-compose up --build

Problema: Visualização 3D branca/preta
Solução: Verificar logs do console (F12)
  - Procurar por "[Canvas] ❌ Erro"
  - Procurar por "[WebGL] ❌ WebGL não disponível"
  - Procurar por shader errors
